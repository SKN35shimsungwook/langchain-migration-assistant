# 작업기록 · 프로젝트를 하면서 만든 파일 전체

> 4번(화면 · DB · 평가 · 발표)이 AI 코딩 도우미(Claude Code)와 함께 프로젝트를 진행하며 만든 **보조 스크립트 · 중간본 · 그림 · 시험 기록**을 날짜와 목적별로 모은 폴더입니다.
> 앱 실행에는 필요 없습니다. 무엇을 어떻게 만들었는지 되짚어 보고, 같은 산출물을 다시 만들 때 씁니다.
> 전체 진행 기록(대화 순서대로)은 [docs/작업_기록.md](../docs/작업_기록.md)에 있습니다.

## 정리 원칙

- **비밀 값 없음**: API 키 · DB 비밀번호는 넣지 않았습니다 (`.env` 자리 표시 `sk-...`, `TIDB_PASSWORD=...` 만 있음). 올리기 전에 검사했습니다
- **팀원 실명 없음**: 역할 번호(1 · 2 · 3 · 4번)로 바꿨습니다
- **뺀 것**: 브라우저 프로필(PDF 만들 때 생긴 임시 폴더), 시험용 SQLite DB, 파이썬 패키지 사본, 팀 저장소 코드 사본(시뮬레이션용 복사본), TiDB 백업(대화 내용 포함)
- 스크립트 대부분은 임시 작업 폴더에서 실행했으므로, 실행할 때 경로를 인자로 넘깁니다 (각 파일 맨 위 설명 참고)
